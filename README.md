# DonutClients GitHub Pages

This repository is an automatically generated public mirror of the DonutClients website.

Source of truth: `donutclients/donuthub`

Do not develop the website independently in this repository. Website changes must be made in `donutclients/donuthub` and then published here by the synchronization workflow.

The GitHub Pages version is the static public build. Server-side functionality such as the protected admin backend remains on the Cloudflare deployment.
